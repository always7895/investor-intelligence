# Code of conduct

This project expects respectful, evidence-based collaboration. Keep discussions professional; challenge claims and methods rather than people. Harassment, threats, discriminatory abuse, doxxing, spam and deliberate disclosure of private or licensed material are not acceptable.

For routine disagreements use the appropriate issue or review thread and cite reproducible evidence. For sensitive conduct concerns, approach the repository maintainers through an existing private channel rather than publishing personal details. There is no public enforcement contact address verified in this repository.

Maintainers may moderate discussions and reject contributions to protect privacy, security, source licensing and project scope. These norms do not change Production permissions or the [security reporting](SECURITY.md) procedure.
