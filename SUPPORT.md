# Support

For non-security behavior, setup or documentation questions, open a GitHub issue **if the repository issue tracker is available to you**. Include the repository revision, OS/tool versions, command, expected result, sanitized observed result, and the relevant [documentation link](docs/README.md).

Start with [README](README.md), [dependency setup](docs/DEPENDENCY_LOCKING.md), [operator runbook](docs/OPERATOR_RUNBOOK.md) and [current status](state/STATUS.md). An issue is not a Production support SLA, permission to deploy, a live quote guarantee, or advice to trade.

Do not paste channel secrets, tokens, LINE/user IDs, private positions, broker records, or unlicensed source text. For a suspected vulnerability, use [private security reporting](SECURITY.md), not a public issue.
